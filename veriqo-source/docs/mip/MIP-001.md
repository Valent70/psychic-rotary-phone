## 2. W4 — what was built and why it was missing

The scan that opened this round found **zero** files matching
`reverseproof`, `OBSERVED_ABSENT`, `nextbest`, `SingleSourceException`,
`ControlledView`, `AIContribution`, `ProtectiveOrder`, `constitution`,
or `EventEnvelope`.

That is the honest gap: VERIQO had trust calculus, contradiction, and
dependency analysis, but not the epistemic frame that makes them
answerable — no reverse proof to say what evidence *should* exist, and
no observability gate to distinguish "absent" from "we didn't look."

New packages, each extending rather than replacing:

| Package | Extends | Does not duplicate |
|---|---|---|
| `pkg/constitution` | — (new authority-free checker) | Emits no events, holds no state |
| `pkg/contract/event` | `pkg/platform/audit` chain semantics | Adds no second ledger |
| `pkg/qualification/reverseproof` | `pkg/insurance/causation` hypotheses | Does not re-implement hypothesis sets |
| `pkg/qualification/observability` | — | Distinct from `pkg/blockers/coverage` (ops coverage, not epistemic) |
| `pkg/qualification/independence` | `pkg/insurance/evidence/dependency.go` concepts | Canonicalizes across 15 dimensions rather than forking |
| `pkg/qualification/state` | `pkg/insurance/evidence/qualification.go` | Adds the canonical 9-state vocabulary + single-source exception |
| `pkg/qualification/nextbest` | — | Pure ranking over policy-filtered candidates |
| `pkg/disclosure/access` | `pkg/authz` purpose binding | Adds the two-dimensional P/C lattice authz lacked |
| `pkg/ai/gateway` | `pkg/authz`, `pkg/disclosure/access` | Composes them; adds no policy engine |

## 3. The anti-duplication audit

Per §7, for each capability the MIP names, the question *"does this
already exist?"* was answered before writing code:

| MIP capability | Answer | Action taken |
|---|---|---|
| Event ledger | `pkg/platform/audit` — hash-chained, Merkle, verified | **Extended** with a canonical envelope. No new ledger. |
| Policy plane | `pkg/authz` — purpose binding, policy decisions | **Extended** with disclosure lattice. No new policy engine. |
| Trust calculus | `pkg/core/trustcalc` | **Reused**. Independence gate added alongside, not inside. |
| Contradiction | `pkg/insurance/contradiction` | **Reused**. |
| Hypothesis | `pkg/insurance/causation` | **Reused** by reverse proof. |
| Retention / legal hold | `pkg/governance/data` | **Reused**. |
| Replay | `pkg/replay`, `Store.Replay` | **Reused**. |
| Verifier | `pkg/commercial/packageverify` | **Reused**. |
| Canonicalization | `pkg/canonical/jcs` | **Reused** by the event envelope hash. |

Forbidden engines from §7 — `AuditEngine`, `DissentEngine`,
`NeutralityEngine`, `ProtectiveOrderEngine`, `ProvenanceEngine`,
`DisclosureEngine`, `RedactionEngine` — **none were created.** Those
capabilities are expressed as canonical state + policy + ledger events,
exactly as §7 requires.
